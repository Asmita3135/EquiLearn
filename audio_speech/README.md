# EquiLearn — Member 2: Audio & Speech Intelligence

This package implements Member 2's responsibilities for the EquiLearn Multimodal Accessibility Intelligence project.

## Core Responsibilities
1. Video → Audio extraction (FFmpeg)
2. Audio preprocessing (16 kHz mono, silence trimming, normalization)
3. Speech Recognition (Whisper)
4. Transcript & Timestamp processing
5. WebVTT Caption Generation
6. Deaf/Hard-of-Hearing Accessibility Workflow
7. Text-to-Speech (TTS) Component / Investigation
8. ASR Error Handling & WER Evaluation
